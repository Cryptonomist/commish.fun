# The Commish kit

Everything here is generated by [`scripts/build-brand.mjs`](../scripts/build-brand.mjs)
from two sources: the Laces geometry in `src/components/Laces.tsx` and the
Pigskin tokens in `src/app/globals.css`. Nothing in this folder is drawn by
hand, and nothing should be edited in place.

```bash
node scripts/build-brand.mjs
```

That is the whole point. The previous kit was exported by hand from a design
file, so when the palette moved from brown-and-orange to Turf every asset in it
went silently wrong and there was no way to tell except by opening them one at
a time. Change a token, re-run the script, and the kit is correct again.

## What is in it

| File | Size | For |
|---|---|---|
| `mark-action.svg` / `.png` | 200 / 512 | The Laces in orange, on transparent |
| `mark-cream.svg` / `.png` | 200 / 512 | The Laces in cream, for dark surfaces that are not night |
| `mark-night.svg` | 200 | The Laces in near-black, for light surfaces |
| `avatar.svg` / `.png` | 512 | The mark on its own ground, square. Profile pictures |
| `appicon.png` | 1024 | App stores, large icons |
| `favicon-180.png` | 180 | Apple touch icon |
| `banner-x.svg` / `.png` | 1500 × 500 | Social header |
| `og.svg` / `.png` | 1200 × 630 | Link previews. Wired up in `layout.tsx` |

`public/brand/` holds the copies the site actually serves. The script writes
both, so they cannot drift.

## The rules

**The mark never sits on a filled tile.** It used to sit in an orange square,
which is the same shape and colour as every button on the site, so the logo read
as something to click. Orange laces on night are a mark; an orange square with
something cut out of it is a button.

**One accent.** `#FF6A2B` is the brand, the links and the buttons. Gold
`#E9C258` is money only — pot amounts and payouts, nothing else, ever.

**Never redraw the Laces.** One spine, four ticks, rounded ends, tilted 14
degrees. Never stretched, never set inside the wordmark, never given a colour
outside the palette. The illustrated footballs are retired.

## Type

The wordmark is **Anton**, and `fonts/Anton-Regular.ttf` is committed because
the generator needs it: sharp rasterises SVG through librsvg, which resolves
fonts through the system and knows nothing about `@font-face`, so the woff2 the
site ships cannot be used here. The script installs it into your user font
directory on first run.

Anton is licensed under the SIL Open Font License 1.1, included as
`fonts/OFL.txt`. That licence permits redistribution and embedding; it also
requires the licence travel with the font, which is why it is here.

## `archive/`

The previous identity, in the retired brown-and-orange palette, including the
original identity PDF. Kept because it is somebody's design work and not mine to
throw away, moved out of the way because leaving wrong-palette assets beside
correct ones is exactly the trap this generator exists to close. Safe to delete
whenever you are sure you want it gone.
